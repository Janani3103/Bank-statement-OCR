# Bank Statement OCR

An AI-powered Bank Statement OCR system that extracts transaction
information from images and PDF bank statements.

## Features

- Upload bank statement images
- Upload PDF bank statements
- Extract transaction data using Gemini
- Convert extracted information into CSV format

## Extracted Data

- Transaction Date
- Transaction Description
- Amount
- Notes

## Built with

- Google AI Studio
- Gemini
- React
- TypeScript
- Node.js
